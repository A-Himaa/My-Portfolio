# 🌐 Personal Portfolio

A modern, responsive, and visually clean personal portfolio website built using **React-Vite**, and **Tailwind CSS**.  
This portfolio showcases my skills, projects, experience, and personal branding as an aspiring full-stack developer.

---

## 🚀 Features

- ⚡ Built with React + Vite for light-weight and fasr performence 
- 🎨 Tailwind CSS for clean, modern UI and reusable design
- 📱 Fully responsive layouts  
- 🧩 Reusable components & scalable architecture  
- 🌙 Smooth animations & transitions  
- 🔗 Easy navigation with section-based scrolling  
- 🧑‍💻 Showcases projects, experience, skills and contact section  

---

## 🛠️ Tech Stack

**Frontend:**  
- React  
- Vite  
- Tailwind CSS  

**Tools & Libraries:**  
- Framer Motion (optional animations)  
- React Icons  
- CSS Variables for theme (custom color palette, shadows, transitions)

## Installation

Follow these steps to run the project locally.

### 1. Clone the repository

```bash
git clone https://github.com/A-Himaa/My-Portfolio.git
```

### 2. Navigate to the project directory

```bash
cd my-portfolio
```

### 3. Install dependencies

Using npm:

```bash
npm install
```

### 4. Start the development server

Using npm:

```bash
npm run dev
```

### 5. Open in your browser

Visit:

```
http://localhost:5173
```
